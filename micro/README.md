# Micro Hub (3BE123)

A static, no-build study web app for **VŠE Prague 3BE123 (Microeconomics)**: step-by-step lessons, a formula coach with new numbers every time, interactive graphs, 4-star Mastery, games, mock tests, review, a dictionary and the Study Cat. Third hub next to Statistics Hub and Geology Hub, built on the same engine.

- Run locally: `python3 -m http.server 8000` → open `http://localhost:8000`
- Validate data: `node tools/validate.js courses/micro`
- Add a lecture: see `AUTHORING.md` and `PROMPT.md`; for graphs and drills see `lib/graphs.js`
- Start with `HANDOFF.md`
