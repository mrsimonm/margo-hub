# Op Man Hub (3BE216)

A static, no-build study web app for **VŠE Prague 3BE216 Operations Management** (Felipe Martinez): step-by-step lessons, drag-and-drop exercises, calculation drills with new numbers every time, the real practice-test exercises, 90-minute mock tests, Mastery, games, review, a dictionary and the Study Cat. Same engine as Micro Hub and Statistics Hub; it is also synced into Margo's Study Hub (`~/Projects/margo-hub/opman`).

- Run locally: `python3 -m http.server 8000` → open `http://localhost:8000`
- Validate data: `node tools/validate.js courses/opman`
- Add a lecture: see `AUTHORING.md` and `PROMPT.md`; for widgets and drills see `lib/opman.js`
- Start with `HANDOFF.md`
